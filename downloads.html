Installing for the first time

  1. Tap a download above. Your browser will warn you about the file type — that warning is for any APK, not this one.
  2. Open the downloaded file. Android will ask whether this browser may install unknown apps. Allow it once.
  3. Install. No permissions are requested — none of these apps ask for storage, camera, contacts or location.

Updating: export your data first

These are self-signed builds, and the signing key is regenerated on each build machine. Android refuses to install an update signed by a different key, so a new version will fail with App not installed until you uninstall the old one — and uninstalling erases that app's data.

So before updating: open the app, use its Export / backup panel, copy the text somewhere safe. Install the new version, then paste it back into Restore. Games, history, settings and lesson progress all come back.

To make updates install cleanly over the top instead, add a fixed signing key to the repository as the ANDROID_KEYSTORE_BASE64 secret. Every build then shares one signature and Android treats them as the same app.

Sizes and checksums are read from the GitHub releases when this page loads, so they always describe the build you are about to download rather than whatever was current when the page was written.

Every app is also linked to its web version above. Those need no install — open one once and it caches itself, so it keeps working offline, and Add to Home screen gives it an icon that opens without browser chrome.

Worth knowing: the installed app and the web version keep separate data. They are different storage, so games, settings and progress do not carry across. Moving between them means exporting from one and restoring into the other.
