# Life Architecture Vault

This folder is a personal knowledge base in the Obsidian style: plain Markdown
files with YAML frontmatter and `[[wikilinks]]`. No app owns this data — it
lives in git and any Markdown tool can read it.

## How to use it

1. Install [Obsidian](https://obsidian.md) (free, local-first) or
   [Logseq](https://logseq.com) (open source).
2. In Obsidian: **Open folder as vault** → select this `vault/` directory
   (clone the repo to your computer first).
3. Edit, link notes with `[[Note Name]]`, and commit/push to sync.

## Structure

| Folder | Purpose |
|---|---|
| `00 Inbox` | Quick capture — unsorted notes to file later |
| `10 Projects` | Active projects with a defined outcome |
| `20 Areas` | Ongoing life areas (health, finances, learning…) |
| `90 Discussions` | Transcribed/summarized conversations and decisions |

## Conventions

- One note per topic; file name is the note title.
- Frontmatter keys used so far: `date`, `tags`, `status`.
- Discussion notes are named `YYYY-MM-DD Topic.md`.
