# Life Architecture App

A personal life-gamification PWA: React + Vite, deployed to GitHub Pages,
with Firebase authentication and per-account cloud storage in Firestore.

## Milestones so far

- Scaffolded as a Vite + React PWA for GitHub Pages deployment.
- Replaced App.jsx with LifeArchitecture v8; storage migrated to localStorage.
- Added GitHub Actions workflow for automatic Pages deployment.
- Added Firebase authentication and per-account cloud storage.
- Firestore seeded with local data on first login.
- Daily XP banked cumulatively so level never resets.
