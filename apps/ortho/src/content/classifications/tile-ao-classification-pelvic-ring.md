## Overview

The Tile/AO classification grades pelvic ring injuries by **mechanical stability** — Type A (stable), Type B (rotationally unstable, vertically stable), and Type C (rotationally and vertically unstable) — with numbered subtypes describing the specific pattern. Because it maps directly onto whether posterior fixation is required, it is the preferred classification for surgical decision-making in pelvic ring injury.

## Types

| Type/Grade | Definition | Treatment implication |
|---|---|---|
| **A1** | Avulsion fracture (ASIS, AIIS, ischial tuberosity), ring intact | Symptomatic treatment, protected weight-bearing |
| **A2** | Stable, minimally displaced ring fracture (isolated rami, iliac wing) | Nonoperative |
| **A3** | Transverse sacral/coccygeal fracture without ring instability | Nonoperative |
| **B1** | Open-book (external rotation), unilateral | Anterior ± posterior fixation depending on posterior ligament integrity |
| **B2** | Lateral compression, ipsilateral | Usually nonoperative unless displaced/crescent |
| **B3** | Bilateral type B | Bilateral anterior fixation ± posterior stabilization |
| **C1** | Unilateral complete posterior ring disruption | Posterior fixation (screws or plate) + anterior fixation |
| **C2** | Bilateral, one side C-type, other side B-type | Bilateral posterior fixation strategy tailored to each side |
| **C3** | Bilateral complete disruption | Most unstable pattern; often requires combined posterior + anterior fixation, staged |

## Pearls

- Tile/AO is the preferred classification for **surgical decision-making** because it maps directly onto whether posterior fixation is required.
- Young-Burgess better predicts **hemorrhage magnitude**; use both classifications together in practice rather than either alone.
- Stability in the pelvic ring is predominantly determined by the **posterior** SI ligament complex, not the anterior ring — this is the biomechanical basis for the A/B/C stability grading.
- C2 (bilateral, mixed B/C sides) requires a fixation strategy individualized to each side rather than a single symmetric construct.
