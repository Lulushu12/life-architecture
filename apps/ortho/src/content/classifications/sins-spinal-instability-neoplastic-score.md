## Overview

The Spinal Instability Neoplastic Score (SINS) is a six-domain, 0–18 point scoring system developed by the Spine Oncology Study Group to assess mechanical instability from spinal neoplastic disease. It is scored from location, pain character, bone lesion quality, spinal alignment, vertebral body collapse, and posterolateral element involvement, and is the "mechanical" axis of the NOMS decision framework for metastatic spine disease — mechanical instability drives the decision to stabilize independent of tumor radiosensitivity or systemic status.

## Types

| Component | Finding | Points |
|---|---|---|
| **Location** | Junctional (occiput–C2, C7–T2, T11–L1, L5–S1) | 3 |
| | Mobile spine (C3–C6, L2–L4) | 2 |
| | Semi-rigid (T3–T10) | 1 |
| | Rigid (S2–S5) | 0 |
| **Pain** | Mechanical/positional pain | 3 |
| | Occasional non-mechanical pain | 1 |
| | Pain-free lesion | 0 |
| **Bone lesion quality** | Lytic | 2 |
| | Mixed lytic/blastic | 1 |
| | Blastic | 0 |
| **Spinal alignment** | Subluxation/translation present | 4 |
| | De novo deformity (kyphosis/scoliosis) | 2 |
| | Normal alignment | 0 |
| **Vertebral body collapse** | >50% collapse | 3 |
| | <50% collapse | 2 |
| | No collapse but >50% body involved | 1 |
| | None of the above | 0 |
| **Posterolateral element involvement** | Bilateral (facet/pedicle/costovertebral) | 3 |
| | Unilateral | 1 |
| | None | 0 |

**Total score → management**: **0–6 = stable** (no surgical stabilization needed on mechanical grounds); **7–12 = indeterminate** (potentially unstable — obtain spine surgical consultation); **13–18 = unstable** (surgical stabilization indicated regardless of radiosensitivity or systemic status considerations).

## Pearls

- Mechanical (position-dependent) pain over a known bony metastasis should be treated as SINS-unstable until formally scored — mechanical instability is not a radiation-fixable problem, and this pain pattern is a red flag.
- In the NOMS framework, mechanical instability (SINS 13–18) drives stabilization **regardless of ESCC grade or radiosensitivity** — it is an independent axis from the neurologic/oncologic decision, not a tiebreaker.
- Vertebroplasty/kyphoplasty is effective for mechanical pain from a pathologic compression fracture without significant posterior wall compromise or high-grade epidural extension, but is **not a substitute for stabilization** when the SINS score is unstable.
- SINS 7–12 (indeterminate) warrants a spine surgical consultation rather than a default management pathway — it is not simply "watch and rescan."
