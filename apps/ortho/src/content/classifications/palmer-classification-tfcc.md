## Overview

The Palmer classification categorizes triangular fibrocartilage complex (TFCC) lesions into traumatic (Class 1) and degenerative/ulnocarpal impaction (Class 2) pathways, with subtypes describing tear location. It remains the clinical reference standard for communicating and coding a TFCC tear found at MRI or arthroscopy, distinguishing acute traumatic injury from chronic degenerative overload. For acute trauma (the scope of this monograph), Class 1 is the clinically relevant category; Class 2 is a separate chronic pathway, included here for completeness.

## Types

| Class | Subtype | Description | Treatment implication |
|---|---|---|---|
| **1 — Traumatic** | 1A | Central perforation/tear of the articular disc | Avascular zone — debridement (arthroscopic) if symptomatic; not repaired |
| | 1B | Peripheral (ulnar) avulsion, ± ulnar styloid fracture | Well-vascularized zone — primary repair (arthroscopic or open) if DRUJ unstable or symptoms persist after conservative trial |
| | 1C | Distal avulsion (ulnocarpal ligaments — ulnolunate/ulnotriquetral) | Repair if causing ulnocarpal instability; can be technically demanding arthroscopically |
| | 1D | Radial-sided avulsion, ± sigmoid notch fracture | Repair (transosseous technique to radius) if DRUJ instability present |
| **2 — Degenerative (ulnocarpal impaction spectrum)** | 2A | TFCC wear, no perforation | Conservative (activity modification, ulnar shortening not usually indicated yet) |
| | 2B | TFCC wear + lunate and/or ulnar chondromalacia | Conservative first; consider ulnar shortening osteotomy if positive ulnar variance and impaction symptoms |
| | 2C | TFCC perforation + lunate/ulnar chondromalacia | Debridement ± ulnar shortening |
| | 2D | TFCC perforation + chondromalacia + lunotriquetral ligament perforation | Debridement, possible LT stabilization, ulnar shortening |
| | 2E | Above + ulnocarpal arthritis | Salvage (e.g., wafer procedure, ulnar shortening, or arthroplasty/fusion depending on severity) |

## Pearls

- Vascular zonation (Palmer/Bednar) underlies the whole repair-vs-debride decision: the peripheral 10–20% (ulnar attachment) is well vascularized and heals with repair; the central 2/3 to 80% is relatively avascular with poor healing potential and is managed by debridement when symptomatic.
- The deep, foveal ("ligamentum subcruentum") fibers of the TFCC — distinct from the more peripheral, better-vascularized superficial fibers inserting onto the ulnar styloid base — are the critical DRUJ-stabilizing structure; a Palmer subtype alone does not capture foveal involvement, which is why classification of instability requires separate clinical/intraoperative assessment.
- Newer arthroscopic classification schemes (the 2022–2023 "CUP" — Central/Ulnar/Peripheral — classification, and a disc/reins/wall "D-R-W" scheme) have been proposed to address Palmer's limitations in guiding repair technique, but Palmer remains the clinical reference standard for routine communication and coding.
- Do not conflate pathways: ulnar shortening osteotomy is a Class 2 (degenerative) procedure, not an acute Class 1 trauma intervention.
