## Overview

The SRS-Schwab classification (2012) grades adult spinal deformity by coronal curve type plus three sagittal modifiers, each graded 0/+/++ for severity. It reflects the central conceptual shift from pediatric to adult deformity surgery: health-related quality of life correlates more strongly with **sagittal** malalignment than with absolute coronal Cobb angle, so the sagittal modifiers — not curve type — are what drive surgical planning.

## Types

| Type/Grade | Definition | Treatment implication |
|---|---|---|
| **T (thoracic)** | Thoracic curve only (lumbar Cobb <30°) | Coronal descriptor; sagittal modifiers still drive correction magnitude |
| **L (lumbar)** | Thoracolumbar/lumbar curve only (thoracic Cobb <30°) | Coronal descriptor; sagittal modifiers still drive correction magnitude |
| **D (double)** | Double curve (both ≥30°) | Coronal descriptor; sagittal modifiers still drive correction magnitude |
| **N (none)** | All Cobb <30° — sagittal deformity present without significant coronal curve | Common in de novo degenerative deformity; surgical planning driven entirely by sagittal modifiers |
| **PI-LL mismatch: 0 / + / ++** | <10° / 10–20° / >20° | Higher grade = greater lordosis restoration needed; drives choice of interbody vs. osteotomy technique |
| **SVA (C7 plumb to posterosuperior sacrum): 0 / + / ++** | <4cm / 4–9.5cm / >9.5cm | Higher grade correlates with worse ODI/SRS-22; target is restoration toward "0" |
| **PT (pelvic tilt): 0 / + / ++** | <20° / 20–30° / >30° | Reflects compensatory pelvic retroversion; higher grade signals exhausted compensatory reserve |

## Pearls

- Higher-grade sagittal modifiers correlate directly with worse ODI and SRS-22 scores and are the primary driver for selecting more aggressive correction techniques (osteotomy grade, fusion length, need for anterior column support).
- Surgical planning targets restoring modifiers toward "0," ideally using **age-adjusted** targets rather than one absolute number for every patient — some PI-LL mismatch and PT elevation is physiologic with aging. A 2023 comparative study found differences in clinical outcomes and proximal junctional failure rates between normative and age-adjusted correction targets, supporting the age-adjusted approach.
- The Roussouly/Lafage sagittal shape classification is a useful adjunct for individualizing the correction target rather than applying a single fixed number.
- The **Global Alignment and Proportion (GAP) score** has been directly validated against SRS-Schwab: both predict surgical outcomes, with mechanical complication rates rising sharply from ~6% in proportioned spinopelvic states to 47% (moderately disproportioned) and 95% (severely disproportioned) by GAP category — use the two systems together in preoperative planning.
- HRQOL correlates more strongly with sagittal malalignment than with coronal Cobb angle — do not anchor surgical decision-making to the coronal curve type alone.
